# Nova Wing — Web v1.17.0

## O que mudou

- Confirmação dos tiros no ponto real de contato, distinguindo **PONTO FRACO**, **ACERTO** e **SEM DANO**.
- Nos chefes, impactos bloqueados deixam clara a necessidade de outro ângulo; danos confirmados mostram a quantidade real aplicada.
- Efeitos de áudio sintetizados e discretos para ponto fraco e blindagem, com cooldown para reduzir fadiga.
- Melhor leitura em dispositivos móveis com etiquetas compactas; PT-BR/EN/ES seguindo a preferência atual.
- [Backlog público priorizado](../docs/BACKLOG.md) para próximas entregas de variedade de confrontos, upgrades, intro cinematográfica, case e apps nativos.

## Preservado

Sem rebalancear dano, munição, upgrades, cooldown, física de disparos, setores, checkpoints, naves ou pilotos. A publicação é da **web**; Android e iOS requerem homologação e builds próprios.

## Evidência antes da publicação

A implementação deve passar pelos gates: `npm run format`, `npm run build`, `npm run validate -- --browser` e checks da branch de release, com conferência das capturas de WebGL e regressão de pontos fracos. Para validar áudio real, será necessário um navegador com interação do usuário e dispositivo físico.
